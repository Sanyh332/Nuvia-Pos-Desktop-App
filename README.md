# Nuvia POS — Desktop downloads

Installers for **Nuvia Desktop**, the version of Nuvia POS that runs on the
shop's own machine.

This repository holds releases only. The application source is private.

## Download

The current installer is on the [releases page](../../releases/latest).

Windows 10 or later, 64-bit.

## What it is

Nuvia Desktop keeps the database on the counter machine rather than reaching
across the internet for every screen, so the till opens in seconds and keeps
working when the connection does not. It signs in with the same account as the
web app and syncs with it.

## Installing

1. Download the installer.
2. Windows will warn that the publisher is unrecognised — the build is not yet
   code-signed. Choose **More info**, then **Run anyway**.
3. It installs for the current user only. No administrator password is needed.
4. Sign in with your Nuvia account. The first sign-in needs an internet
   connection and copies your shop's catalogue to the machine; it takes a few
   seconds.

Uninstalling leaves your data in place.
